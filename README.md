# Maison Auréa — conceito de site para salão premium

Protótipo de uma landing page cinematográfica para salão de beleza, inspirado na lógica editorial e nas interações de PieterKoopt®, mas redesenhado para uma marca própria em branco, champagne, dourado e bronze.

## Como visualizar

Abra `index.html` no navegador. Para evitar limitações de CORS e garantir o carregamento correto das bibliotecas, prefira um servidor local:

```bash
cd maison-aurea
python3 -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Tecnologias

- HTML, CSS e JavaScript puros
- GSAP + ScrollTrigger
- Lenis para rolagem suave
- Web Audio API para microefeitos sonoros
- Google Fonts: Cormorant Garamond e Manrope

## Pontos para substituir antes de publicar

- Nome “Maison Auréa”
- Telefone e link do WhatsApp
- Endereço, e-mail e redes sociais
- Fotografias por imagens próprias do salão
- Textos dos serviços e horários

As imagens atuais são referências externas para prototipação e devem ser substituídas por conteúdo licenciado ou produzido para a marca final.
